# Biome Styles (T2 & T3)

Palette, roof, and feature guidance per biome. Read in Phase 1.5 (to pick
palette) and Phase 2 (to confirm blocks exist in `registry_26_3.json`).
T1a/T1b/T1c builds skip this file unless the user explicitly asks for a
biome-matched look.

---

## Plains

| Aspect | Detail |
|---|---|
| **Primary** | Oak planks, cobblestone |
| **Secondary** | Oak log, stone bricks |
| **Accent** | Spruce trapdoor, hay bale, flower pot |
| **Roof** | Gable, oak stairs, 2:1 pitch |
| **Height** | 1–2 stories |

## Biome Selection Helper

If the user did not pick a biome, choose based on context:

| Context | Suggested biome |
|---|---|
| "rumah villager" | Plains or Taiga |
| "toko di desa" | Plains (default village) |
| "kastil" | Windswept / Mountain |
| "tenda camping" | Taiga or Forest |
| "rumah pantai" | Beach / Coastal |
| "kuil" | Jungle or Desert |
| "penginapan" | Plains or Savanna |
| "menara" | Windswept / Mountain |
| Unspecified | Plains (safest default) |

State the biome choice explicitly in the response so the user can correct it.
